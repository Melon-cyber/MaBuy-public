## 🛡 4. Три фундаментальных правила экономии токенов

### Правило 1: Никогда не ставить LLM на горячий тиковый путь (Hot Trading Path)
> [!CAUTION]
> **ЗАПРЕЩЕНО** вызывать API Astra внутри циклов `scan_market()`, `execute_trade()` или 10-секундного трейлинга.
- GBDT + PyTorch Attention LSTM в оперативной памяти VPS выполняют инференс за **<15 миллисекунд** при **$0 затрат** и нулевом сетевом риске.
- Astra работает **строго асинхронно в фоне** и раз в 4 часа (или по событию) записывает макро-вектор в SQLite, откуда даймон считывает его без задержек.

### Правило 2: Строгий JSON Output (`response_format={"type": "json_object"}`)
Каждое вводное слово нейросети («*Конечно! Вот мой анализ текущей ситуации на рынке криптовалют...*») стоит $0.05 / 1k токенов.  
Во всех сервисах принудительно задаётся JSON-схема:
```python
# Пример идеального экономного вызова для Макро/Сентимента:
response = client.chat.completions.create(
    model="gpt-6-astra",
    reasoning_effort="low",  # Достаточно для структурирования сентимента
    response_format={"type": "json_object"},
    messages=[
        {"role": "system", "content": SYSTEM_PROMPT_CACHED},
        {"role": "user", "content": user_payload}
    ],
    max_tokens=350,
)
```
**Результат**: ответ занимает ровно 120–250 токенов, экономя более 60% бюджета на output-токенах.

### Правило 3: Использование Prompt Caching (-90% на Input)
OpenAI автоматически кэширует статичные префиксы промптов длиной от **1024 токенов**.  
- Системный промпт с описанием риск-профиля MaBuy, структуры метрик (Hurst, Funding, OBI, Volatility) и правил оценки держится неизменным.
- Изменяются только данные свежего среза рынка в `user`.
- Стоимость чтения системного промпта падает с **$10.00 / 1M** до **$1.00 / 1M**.
