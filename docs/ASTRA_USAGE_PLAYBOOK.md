# 🪐 HOW TO USAGEMAX w/ GPT-6 Astra — MaBuy Operational Playbook

> Зафиксировано на основе официального гайда USAGEMAX. 
> Этот регламент определяет выбор уровня рассуждений (Reasoning Effort) для всех задач экосистемы MaBuy, чтобы максимизировать качество и не тратить токены впустую.

---

## 🎚 МАТРИЦА УРОВНЕЙ РАССУЖДЕНИЙ (REASONING EFFORT)

```
┌─────────────────┬─────────────────┬─────────────────┬─────────────────┐
│   Low-Medium    │      High       │   Extra High    │      ULTRA      │
│  (Быстрый ход)  │(Everyday Monster)│(Глубокий аудит) │(Cyber/Architect)│
└─────────────────┴─────────────────┴─────────────────┴─────────────────┘
```

---

### 1. 🔵 Low - Medium (Экономный режим)
**Когда использовать:**
- Быстрый сбор информации, ресерч и формулировки.
- Экспресс-аудит небольшого куска кода или отдельной функции.
- Написание текстов для постов в Telegram-канал `@MaBuyCrypto`.
- Первичные концепты и драфты ("Draft a 3D character for my video game").

**В проекте MaBuy:**
- Форматирование утренних сводок и отчетов по PnL.
- Быстрый анализ новостного фона и настроений (RSS / CryptoPanic).
- Простые расчеты комиссий и сайзинга без сложных нелинейных уравнений.

---

### 2. 🔷 High (Everyday Monster — Рабочая лошадка для всего)
**Когда использовать:**
- Основной рабочий режим для 80% сложных прикладных задач.
- Реализация крупных фичей от начала до конца ("Create a mobile app with a calendar and payment system").
- Написание комплексных модулей фронтенда и бэкенда.

**В проекте MaBuy:**
- Разработка компонентов UI/UX для Telegram Mini App (`public/index.html`).
- Создание интерактивных графиков, виджетов 5 Институциональных Гейтов и карточек побед (Win-Cards).
- Программирование REST API эндпоинтов в FastAPI.
- Обычные рыночные сканы и калибровка параметров трейлинга.

---

### 3. 🟣 Extra High (Глубокий квантовый аудит & отладка)
**Когда использовать:**
- Глубокий дебаг сложных скрытых багов (Heisenbugs, race conditions).
- Аудит устойчивости алгоритма и проверка граничных условий ("Deep code audits, bugs + fixes").
- Миграции баз данных без простоя продакшна ("Migrate to the upgraded database without impacting uptime").

**В проекте MaBuy:**
- **Разбор сбоев депозита и распила (Churn Diagnosis):** математический расчет оптимального кулдауна, как при аудите лотов BTC.
- Валидация еженедельного переобучения моделей (Out-of-Sample Sharpe Ratio $\ge 1.20$, Directional Accuracy $\ge 52.5\%$).
- Синхронизация SQLite WAL checkpoints и предотвращение блокировок базы данных.
- Проверка каузальности признаков (исключение заглядывания в будущее / lookahead bias).

---

### 4. 🔮 ULTRA (Cybersecurity & Maximum Architectural Power)
**Когда использовать:**
- Самый мощный режим рассуждений в истории AI ("Best coding model EVER").
- Комплексный аудит кибербезопасности и поиск любых скрытых уязвимостей ("Find every security vulnerability in my codebase and fix it").
- Создание сложнейших многопользовательских систем и трехмерных симуляций с нуля ("Create a multiplayer GTA style open world game", "Real 3D scale model of NYC").

**В проекте MaBuy:**
- **Аудит безопасности API-ключей и биллинга:** проверка изолированности сессий Binance, проверка отсутствия утечек в логах, аудит прав на вывод средств (`enableWithdrawals: False`).
- **Стресс-тестирование риска ликвидации:** моделирование сценариев типа «Черный лебедь» (Black Swan) с мгновенным падением рынка на 30% за 5 минут.
- Полная архитектурная перестройка торгового ядра (переход с V4 на V5/V6).
- Проектирование распределенной инфраструктуры при переходе на проп-трейдинг капитал от $100k+.
